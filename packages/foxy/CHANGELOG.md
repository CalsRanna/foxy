# 更新日志

发布流水线读取最新一条版本段作为更新说明(`latest.yaml` 的 `notes`)。
发布前请为本版本补充 `## vX.Y.Z` 段。

## v1.2.3

### 新增

- 雕文属性列表显示技能名称与图标;法术详情中 APPLY_GLYPH 效果支持弹出雕文选择器。
- 宝石属性列表显示本地化附魔名称(优先中文,否则英文)。
- 物品扩展花费列表显示物品详情:前两个物品槽位解析物品名称、图标与品质,拆分为物品与数量两列。
- 下拉选择器新增搜索能力,可按显示文本或值过滤选项。

### 改进

- foxy_lint 新增 `min_table_column_width` 规则,约束表格列最小宽度。

### 修复

- 修复雕文插槽类型显示颠倒的问题:GlyphSlotFlags 0=大型雕文、1=小型雕文。
- 修复部分表格列宽不足、长内容被截断的问题。
- 修复损坏的配置文件自愈时备份未完成即被覆盖的问题。

## v1.2.2

### 新增

- 一键导出 DBC+MPQ：将选中的 DBC 表合并为一个任务同时导出为 DBC 文件与 MPQ 补丁，只读取一次数据库。
- 保存物品模板时同步 Item.dbc：物品的新增、修改、删除会自动更新对应的 Item.dbc 行，导出的 Item.dbc 与服务端所有物品保持一致；该同步为尽力而为，不影响物品本身的保存。
- 天赋列表显示本地化名称与图标。
- 技能线与技能列表补充本地化名称、描述、图标等详情。
- 导出时检测缺少行序数据的表并提示重新导入，避免顺序敏感的表（如 Talent）导出乱序。

### 改进

- spell_item_enchantment 列表移除冗余的 effect1/effect2 列。

### 修复

- 修复导出 MPQ 补丁时默认文件名扩展名使用小写 `.mpq` 的问题，现在统一为大写 `.MPQ`。

## v1.2.1

### 新增

- 导出 DBC/MPQ 时保留数据在源文件中的原始行序，顺序敏感的表（如 Talent）往返导出后保持一致。

### 修复

- 修复导出到不可写目录时错误提示不准确的问题，现在会显示对应的中文错误说明。
- 修复 DBC 导入/导出、图标提取任务运行期间进度对话框可被 Esc/返回键关闭、导致任务在后台继续运行的问题。
- 修复任务完成后设置页的 DBC/MPQ 按钮仍处于禁用状态、无法再次操作的问题。

## v1.2.0

### 新增

- 导出 MPQ 补丁:将选中的 DBC 表打包为补丁文件(默认 `patch-zhCN-5.mpq`),放入客户端后即可覆盖原始 DBC。
- 服务端目录自动检测:只需选择服务端根目录,程序会自动找到 DBC 文件所在位置,与客户端目录的设置方式统一。
- 技能线管理模块。
- 启动时发现 DBC 数据缺失会提醒并引导导入。

### 修复

- 修复部分系统上导出到指定目录失败的问题。
- 导出任务运行期间,其他导入/导出操作会正确禁用,避免冲突。

## v1.1.3

### 新增

- 表格中缩放属性分布类数值字段以可读的适配徽章显示。
- 更多数值字段在表格中显示为可读标签。

### 修复

- 修复更新检查:预发布(alpha/beta/rc)版本不再拦截后续正式版本,更新提示会正确检测到更高的正式版。
- 修复发布流水线:更新清单现在会保留历史版本记录。

## v1.1.2

### 新增

- 表格中双击任意一行即可打开编辑窗口，操作更快捷。
- 编辑窗口样式统一调整。
- 详情页标签自动滚动到当前激活的标签，切换页面时更跟手。
- 活动日志现在会记录操作对应的数据表，历史操作一目了然。

### 修复

- 修复部分 MySQL 8 服务器无法连接的问题。
- 修复标志选择窗口在窄窗口下的显示问题。

## v1.1.1

### 修复

- 更新检查对话框中的更新日志乱码（更新清单按 UTF-8 解码）。
- 下载完成后重启失败时显示失败原因，不再表现为按钮无响应。

### 新增

- 自动更新：设置页「关于与更新 → 检查更新」可手动检查；每次启动自动检查一次（24 小时内不重复）。
- 设置页展示当前版本与项目主页入口。
- locale 编辑拆分为独立编辑器并迁移到 FoxyLocalePicker；新增带符号字段选择器 FoxySignedEntityPicker。
- 默认窗口尺寸调整，新增调试日志开关。
- codebook 支持 BLP 图片格式。

### 改进

- 类型化表格 FoxyDataTable 替换 FoxyShadTable（部分页面已迁移，其余迁移持续进行中）。
- 表单分区与字段组结构重构；详情页面包屑标签统一。
- 条件来源类型标签精简。
- SQL 关键字统一小写。
- 代码注释与文档统一为英文。

### 修复

- 窄窗口下表格列宽出现负值。
- 数据库与表强制 utf8mb4 字符集。
- LIKE 查询通配符转义、配置自愈、DBC 备份表清理、查询超时更新。
- 选择器预选行高亮。
- 详情页监听拆分、链目标字段链接、tab/选择器/图标稳定性加固。
- 数据库查询日志仅在调试模式记录。
- 设置向导「进入应用」按钮无法关闭对话框。
- codegen：关联表活动日志、刷新异常不再重抛、重复 store 重试。

### 性能

- 减少启动时数据库查询，跳过冗余 DDL。

### 构建

- codegen 依赖移至 dev_dependencies，codegen 测试纳入 CI。
- Windows 发布工作流支持预发布 tag（如 `v1.1.0-beta`）。
