# 更新日志

发布流水线读取最新一条版本段作为更新说明(`latest.yaml` 的 `notes`)。
发布前请为本版本补充 `## vX.Y.Z` 段。

## v1.1.2

### 新增

- 双击表格行快速打开编辑器对话框；各实体编辑器对话框样式统一。
- foxy-tab 自动将活动 tab 滚动至可见区域，并同步激活指示器。
- 活动日志集中持久化：所有写操作经事件监听器统一落库，日志条目记录实体名。
- 代码生成器支持从类名派生注解参数；生成的 repository 携带 `_table` 信息并保护 JOIN 查询。
- 新增 lint 规则 annotation_file_mismatch：注解类必须放在与生成器 glob 匹配的文件中，避免被生成器静默跳过。

### 改进

- 代码生成器与 lint 拆分为独立包（foxy_annotation / foxy_generator / foxy_lint），pub workspace 统一管理，CI 纳入三包测试。
- lint 系统从 custom_lint 迁移到 analyzer 插件。
- 生成器错误消息统一为英文。
- 对话框宽度常量统一；图标+名称行提取为共享组件 FoxyIconText。
- MySQL 非 TLS 连接支持公钥检索认证（MySQL 8 caching_sha2_password）。
- 项目文档（README / AGENTS / codegen）刷新。

### 修复

- 标志选择器对话框内嵌套 Flexible 导致的布局问题。

## v1.1.1

### 修复

- 更新检查对话框中的更新日志乱码（更新清单按 UTF-8 解码）。
- 下载完成后重启失败时显示失败原因，不再表现为按钮无响应。

### 新增

- 自动更新：设置页「关于与更新 → 检查更新」可手动检查；每次启动自动检查一次（24 小时内不重复）。
- 设置页展示当前版本与项目主页入口。
- locale 编辑拆分为独立编辑器并迁移到 FoxyLocalePicker；新增带符号字段选择器 FoxySignedEntityPicker。
- 默认窗口尺寸调整，新增调试日志开关。
- codebook 支持 BLP 图片格式。

### 改进

- 类型化表格 FoxyDataTable 替换 FoxyShadTable（部分页面已迁移，其余迁移持续进行中）。
- 表单分区与字段组结构重构；详情页面包屑标签统一。
- 条件来源类型标签精简。
- SQL 关键字统一小写。
- 代码注释与文档统一为英文。

### 修复

- 窄窗口下表格列宽出现负值。
- 数据库与表强制 utf8mb4 字符集。
- LIKE 查询通配符转义、配置自愈、DBC 备份表清理、查询超时更新。
- 选择器预选行高亮。
- 详情页监听拆分、链目标字段链接、tab/选择器/图标稳定性加固。
- 数据库查询日志仅在调试模式记录。
- 设置向导「进入应用」按钮无法关闭对话框。
- codegen：关联表活动日志、刷新异常不再重抛、重复 store 重试。

### 性能

- 减少启动时数据库查询，跳过冗余 DDL。

### 构建

- codegen 依赖移至 dev_dependencies，codegen 测试纳入 CI。
- Windows 发布工作流支持预发布 tag（如 `v1.1.0-beta`）。

### 更新策略

- 自动更新仅推送正式版本，跳过带预发布后缀的 tag 发布的测试版本。
